# QC OTA release — 2026-10-19

Android 1.62.4+5 Patch 18 and iOS 1.62.4+6 Patch 7 were independently verified stable and active for Colton and Fay. New first-sample registration resolves the currently logged-in username per submission and sends it using the existing gateway identity header. Missing identity blocks registration before any request. Backend creation-only auditing was deployed first; updates preserve the original registrant and historical unknown identities are not inferred.

The release also retains Spanish question display: existing API Spanish is authoritative; an ID-and-original-English compatibility catalog applies only when the property is omitted. Explicit blank/null and edited questions retain the intended original-language fallback. Standards, serialization and result logic are unchanged.

Published OTA source was based on the previous published snapshot plus these QC files; the unrelated manual-pick change already present in the development branch was excluded from the release artifact. Normal factory settings, baseline versions and app identity are unchanged. No offline test entrypoint, credentials or native change was included. Required icon glyphs fit the original baseline; no native-diff bypass was used. iOS linking reports the same 69.1% code sharing as the preceding patch; physical-device activation/performance acceptance is pending.

Tests: QC Spanish compatibility and registration identity fixtures, failure review and submission regressions; changed-code analysis; native/asset/factory-definition checks. Runtime factory definitions stay in the existing external private configuration file and must never be committed. The test fixture contains only question-compatibility fields, not operational records, users or credentials.
